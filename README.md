# EDT BUT

Un emploi du temps pour les étudiants de BUT, plus simple à consulter que l'ADE de l'université.

Le projet démarre : il n'y a pas encore de code.

## Organisation

- `back/` : le serveur qui récupère les cours sur ADE et les envoie au front
- `front/` : le site que les étudiants ouvrent

## D'où vient l'idée

On reprend la méthode d'[EtuEDT](https://github.com/AntoninHuaut/EtuEDT-Back), le projet d'Antonin Huaut : récupérer les emplois du temps via l'export iCal public d'ADE, puis les servir au front. Le code de ce dépôt est entièrement écrit par nous. Aucun fichier d'EtuEDT n'est repris.
